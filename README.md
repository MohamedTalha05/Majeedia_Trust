# Majeedia Trust website

The website of [Majeedia Trust](https://majeedia.org). It is a custom-coded replacement for the previous WordPress/Elementor site, built with **React 19, Vite and React Router**, plain CSS and Lucide icons.

Every page is pre-rendered to static HTML at build time, so:

- search engines and social media previews get each page's own title, description and sharing tags;
- the site is hosted as plain files on Hostinger, with no WordPress, database or Node.js server;
- refreshing or directly opening any URL works.

## Commands

```bash
npm install         # install dependencies
npm run dev         # development server at http://localhost:3000
npm run build       # production build → dist/
npm run preview     # serve dist/ at http://localhost:4173
npm run check       # QA: pages, SEO tags, images, internal links, 404 (add -- --external for external links)
npm run images -- <folder>   # convert original photos to optimised WebP (see scripts/optimize-images.mjs)
```

## Donations

Donations are handled entirely by **MYFUNDBOX** (Donorfit, with Razorpay as the payment processor). Donate buttons link to the MYFUNDBOX pages. Nothing is embedded in an iframe, and no payment data passes through this site. All links are in `src/data/donations.js`. See the notes in that file about Test Mode and the two invalid cause links.

## Contact forms

The Contact and Volunteer forms post to `/api/contact.php`, which emails support@majeedia.org. That script runs only on Hostinger. In local development the form shows an error state rather than a fake success. To use a different form service, set `VITE_FORM_ENDPOINT` in a `.env` file.
